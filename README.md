# VisualBrief ~ Under development

VisualBrief is a web-based application that allows users to generate concise summaries and visual diagrams from uploaded documents or custom text input. Users can quickly extract key points, create structured summaries, and visualize ideas as flowcharts, mind maps, or other diagram formats. 

The platform supports both guest users with limited credits and registered users with a full set of features. It is designed to simplify content understanding and provide a visual representation of information for easier consumption and decision-making. It can generate several types of visuals like ER diagram, flowchart, mindmap etc.

---
This project is under active development. Core functionality such as file uploads, text summarization, and diagram generation is functional, while additional features and improvements are continuously being added.
